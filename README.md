# WGR To-Do List Application

A mobile To-Do List application developed using **Flutter and Dart** during my IT internship at **Wish Group Resources (WGR)**.

The application aims to help users manage, organize, and track their daily tasks through a mobile-friendly interface.

## 📱 Project Overview

The WGR To-Do List Application is a mobile application built with Flutter, Google's cross-platform UI framework.

The project was developed as part of my internship experience, providing practical exposure to mobile application development, UI implementation, application logic, and data management.

## ⚙️ Installation and Setup

### Prerequisites

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- Android Emulator or a physical Android device

### Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Lowshaoxuan/Intern_Project-Wish-Group-Resource-To-Do-List-App-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd wish_group_todolist
   ```

3. Install project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
